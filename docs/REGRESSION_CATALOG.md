# Harness 0.6.1 regression catalog

This catalog is for a builder reproducing the current behavior from source, not a claim that every case was executed on every platform. `F` means the cited regression body was added or changed in commit `6034926` relative to `c4a167e` (the 0.6.1 fix set); mixed `F/G` rows include both new and existing regression bodies; `G` means an existing checked-in guarantee. Each numbered group contains **two distinct cases**, A and B, so the 64 groups below define **128 cases**. The named test is the exact existing Swift/Python test nearest the behavior. A Windows equivalent means a native test to implement against the same observable contract; it is **UNVERIFIED**, not an existing Windows test. For JSON, account, and timing details, use [PROTOCOLS.md](PROTOCOLS.md). Do not interpret fixture tests as physical keyboard, live ChatGPT-account, real third-party capture, or Windows evidence.

For a manual run, record OS/build, monitor topology, scaling, keyboard layout, account availability, configuration, emitted audit sequence, expected and actual state, and whether the test used a synthetic fixture. Never paste prompt text, response text, pixels or tokens into logs. The prior reported baseline for this commit was **375 Swift tests, zero failures, three optional skips; 17 packaging tests; 47 TSAN and 43 ASAN tests (one ASAN skip)**. This document adds no fresh execution claim. Native/hardware and live-account checks remain open.
